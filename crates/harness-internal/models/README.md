# harness-models

The Harness's model client: the HTTP transport that performs the Engine's `Chat` effects against the gateway a client has bound, streaming deltas back to the session, and the `GET /v1/models` catalog fetch. `GatewayClient::complete` sends the Engine's request body, reads the SSE stream under the run's byte cap and timeout, folds it through the shared reassembly in `harness-gateway-client`, and returns one `Completion` with the client-side timing it measured. Private to the Harness family in `crates/harness-internal/`; clients reach it through the `harness` facade. It may depend only on `promptforge`, `harness-gateway-client`, and its container siblings.
